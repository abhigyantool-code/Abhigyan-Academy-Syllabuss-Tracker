# Archived Legacy PostgreSQL Docker Compose Configuration

This `docker-compose.postgres.yml` file is the historical Docker Compose file from the PostgreSQL / Supabase architecture prior to commit `e6422a0` (migration to PocketBase).

It has been moved here from the repository root to prevent Docker Compose CLI conflicts with the canonical `docker-compose.yaml` (which defines the active PocketBase web service).

It is retained solely for historical audit reference.
